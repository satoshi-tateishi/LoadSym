名称 カテゴリ 寸法 (W×D×H) 重量

機材リストをまとめて共通テンプレートとして取り込みます。 UTF-8 と Shift_JIS（Excel 由来）のどちらでも読み込めます。

1行目はヘッダー行にしてください。使用できる列:

必須は name / width_mm / depth_mm / height_mm。 category はカテゴリ名で指定します（未指定・不明の場合は「その他」）。 color は #rrggbb 形式です。 形状は取り込み対象外です。取り込み後に機材を編集して形を付けてください。

色の指定に使える255色のパレットをCSVで書き出せます。スプレッドシートで機材リストを 作るとき、color 列に貼る値をここから選んでください。 荷台のエラー表示に赤を使うため、パレットに赤系は含まれていません。
